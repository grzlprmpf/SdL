# Sprachen der Liebe

Ein interaktives Reflexionstool für Paare und Menschen, die ihre persönlichen Formen von Nähe und Zuwendung besser verstehen möchten.

## Live-Demo

**[Sprachen der Liebe direkt im Browser öffnen](https://grzlprmpf.github.io/SdL/)**

## Funktionen

- Zwei frei benennbare Perspektiven
- Unabhängige Regler für fünf Sprachen der Liebe
- Automatisch berechnete relative Gewichtung
- Notizfelder für persönliche Beispiele und Situationen
- Lokale Speicherung im Browser
- PDF-Export der aktuellen Auswertung
- Hintergrundinformationen und weiterführende Quellen
- Responsives Layout für Desktop und Mobilgeräte

## Nutzung

Die Werte der einzelnen Regler können unabhängig voneinander eingestellt werden. Aus ihrem Verhältnis berechnet die Seite eine Verteilung von insgesamt 100 Prozent. Namen, Werte und Notizen bleiben lokal im jeweiligen Browser gespeichert.

Über **„Auswertung als PDF exportieren“** lässt sich die aktuelle Darstellung einschließlich der Notizen als PDF herunterladen.

## Lokal öffnen

Das Projekt besteht aus einer einzelnen HTML-Seite. Zum Ausprobieren kann `index.html` direkt im Browser geöffnet oder über einen einfachen lokalen Webserver bereitgestellt werden.

## Datenschutz

Die eingegebenen Namen, Reglerwerte und Notizen werden ausschließlich im lokalen Speicher des Browsers abgelegt. Es gibt kein Benutzerkonto und keine Übertragung der Eingaben an einen Server.

## Hinweis

Das Tool dient der persönlichen Reflexion und als Gesprächsanlass. Es ist kein psychologischer Test und ersetzt keine professionelle Beratung oder Therapie.
